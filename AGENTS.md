# PostoGasosa

Sistema de gerenciamento remoto de preços de combustíveis para postos (painel web + gateway IoT → placa de LED).

## Agent skills

### Issue tracker

Issues for this repo are tracked on GitHub Issues via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default triage labels kept as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
